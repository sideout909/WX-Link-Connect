# Display enclosure reference

Search checked October 21, 2026 for the owned **PanelLan ZX2D80CE02S-V10**,
also named **WT32S3-28S PRO** and **SC05_X**. No exact downloadable STEP,
STL or native CAD model was found in the manufacturer resources, GitHub or
indexed results for Printables, MakerWorld, Thingiverse and GrabCAD. This is
a search result, not proof that a model does not exist.

The manufacturer's [Arduino board table](https://github.com/smartpanle/PanelLan_esp32_arduino/blob/master/readme.md)
confirms the SC05_X / ZX2D80CE02S naming. The
[manufacturer product page](https://shop.wireless-tag.com/products/2-8inch-pro-lcd-touch-screen-esp32-s3-display-wt32s3-28s-pro-lcd-module-with-240x320-lcd-display)
identifies WT32S3-28S PRO. Models for the ordinary CYD ESP32-2432S028,
SC05_PLUS or 3.5-inch WT32-SC01 Plus must not be assumed to fit this board.

## Dimensioned drawing

Use **printed page 9, Figure 2**, in the local
[manufacturer datasheet](PanelLan-ZX2D80CE02S-WT32S3-28S-PRO-datasheet.pdf).
[Original manufacturer PDF](https://img03.71360.com/w3/77q677/20250701/255a7c29ee6c23af4b5a41406aa43ffc.pdf).
The drawing labels its part ZX2D80CE02S-V1.0. These are drawing dimensions,
not measurements of the owner's assembled board:

| Feature, landscape orientation | Drawing dimension |
| --- | --- |
| Front outer width × height | 78.00 × 54.90 mm |
| Front outer corner radius | R2.90 mm |
| Side-view overall depth callout | 11.26 mm |
| Four mounting-hole center spacings | 72.40 × 49.20 mm |
| Hole-center inset from right/top outer edges | 2.80 / 2.85 mm |
| Mounting-hole radius callout | R0.94 mm, approximately 1.88 mm diameter |

The drawing also labels a 9.55 mm side-view dimension; retain the original
view when interpreting its datum. The outer front dimensions are not the
active display opening. Check that opening, mounting-hole diameter and the
USB-C/reset/header positions against the actual board before printing a
close-fitting faceplate. The drawing is insufficient to reconstruct all
connector shapes and tolerances as a verified detailed 3D model.

Allow additional rear space for the plugged-in debug/expansion connectors,
their wire bends and the separate CC1101 module/antenna connection. The
11.26 mm dimension alone is not the required enclosure depth for the wired
weather receiver.

For an exact model, the next manufacturer request would be a STEP file and
dimensioned mechanical drawing for **ZX2D80CE02S-V1.0 / WT32S3-28S PRO**.
